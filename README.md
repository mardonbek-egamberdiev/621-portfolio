# Mardonbek Egamberdiyev — Portfolio

## Ishga tushirish
`index.html` faylini brauzerda oching. Internet boʻlsa, shriftlar (Unbounded, Onest) Google Fonts’dan yuklanadi.

## Nimani oʻzgartirish kerak
- **Rasmlar:** `images/profile.png` — profil rasmi. `images/projects/project-1.svg … project-4.svg` — loyiha rasmlari. Oʻz rasmlaringizni (masalan `.jpg`) qoʻyib, `index.html`dagi `src` yoʻlini yangilang. Tavsiya etilgan oʻlcham: 1200×750.
- **Email va tarmoqlar:** `index.html`da `mardonbek@example.com` va GitHub/Telegram/LinkedIn havolalarini almashtiring.
- **Matnlar:** ikkala tildagi matnlar `js/i18n.js` faylida. Loyiha nomlari, tajriba yillari, kompaniya nomlari `index.html`da.
- **Ranglar:** `css/style.css` boshidagi `:root` oʻzgaruvchilari.

## Fayl tuzilmasi
```
index.html
css/style.css
js/i18n.js   — UZ/EN tarjimalar
js/main.js   — mavzu, til, menyu, naqsh animatsiyasi, forma
images/      — profil, favicon va loyiha rasmlari
PROMPT.md    — shu saytni qayta yaratish uchun prompt
```
